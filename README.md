# LMP Clock & Weather

Початковий Android-проєкт на Kotlin + Jetpack Compose.

## Що вже є
- Головний екран у стилі мінімалістичного погодного годинника.
- Поточний час і дата українською.
- Реальні погодні дані Open-Meteo: температура, відчутна температура, вологість, вітер, максимум/мінімум і прогноз на 7 днів.
- Запит дозволу на геолокацію; якщо координати недоступні, використовується Київ.
- Базовий екран налаштувань.

## Відкриття
Відкрий цю папку як наявний Gradle-проєкт в AndroidIDE або Android Studio. Потрібен JDK 17 та Android SDK Platform 35. Дочекайся Gradle Sync, потім Build/Run.

## Погодні дані
Використовується безключовий API Open-Meteo: https://open-meteo.com/ . Для публічного комерційного використання перевір умови ліцензії та атрибуції Open-Meteo.

## Примітка
Це вихідний проєкт, не готовий APK. APK збирається локально AndroidIDE/Android Studio після Gradle Sync.
\n## Віджет головного екрана\n- Додано віджет годинника та погоди для Києва.\n- Час і дата оновлюються системним TextClock.\n- Погода оновлюється у фоновому режимі приблизно кожні 30 хвилин (Android WorkManager може відкладати запуск для економії батареї).\n- Щоб додати: затисни порожнє місце на головному екрані → Віджети → LMP Clock & Weather → перетягни віджет.\n

## Візуальні оновлення
- Погодні значки замінені на Flat Design графіку.
- Додана окрема іконка застосунку без тексту.
- Додано нижній системний відступ на головному екрані, щоб підписи не перекривалися навігаційною панеллю Android.
